# Project brief

Static prototype pages for a fleet management platform.

## Tech
- Plain HTML and CSS only. No frameworks, no build tools.
- One page per file (e.g. vehicles.html).
- File names: lowercase, words joined with hyphens (e.g. drivers-list.html).

## Scope rules
- Only change files the task names. If another file seems to need a change, ask first.
- Never modify README.md unless asked.
- Never remove existing states or content unless the task says to replace them.

## Copy rules
- Sentence case for headings and buttons ("Add vehicle", not "Add Vehicle").
- Buttons start with a verb and say what happens ("Reset filters", not "OK").
- Empty states have: a heading saying what's empty, one sentence on what to do, one primary action.
- No "Oops", no exclamation marks, no blaming the user.

## Pull requests
- In the PR description, list every file changed and every visible change.
